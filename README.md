# タイヤ価格監視ページの仕組み

155/65R14 タイヤの価格を1時間ごとに自動でチェックし、最安値と相場（中央値）の推移を記録・公開する仕組みです。
公開ページ: https://jerrybmg9728.github.io/tire-price-monitor/

## 監視対象

- ブリヂストン ブリザック VRX3（冬用）
- 夏タイヤ（サマー）
- ブリヂストン ブリザック WZ-1

## 価格の集計ルール

- 主要4市場（楽天市場、Yahoo!ショッピング、ヤフオク!、Amazon）の出品だけを集計対象にします。最安値と中央値はこの4市場から算出します。
- モノタロウ、ヨドバシ.com などその他の店舗の価格は「参考価格」として一覧に表示するだけで、最安値・中央値には含めません。
- 各出品は商品ページで単価・本数・送料を確認し、1本あたりの単価に換算して比較します。

## 1時間ごとの流れ

1. 毎時 :31 ごろに価格チェックが自動で起動します。
2. バックグラウンドで各市場の出品を調査し、最安単価、4本セット価格、店舗名、商品ページへのリンク、中央値を記録します。
3. 毎時 :50 ごろに共有ページを最新データで再生成し、このリポジトリの `index.html` を更新します。GitHub Pages 経由で公開されるため、反映はその数分後です。
4. 開始から45分以内に完了しないチェックは「失敗（タイムアウト）」として確定させ、次のチェックが詰まらないようにしています。

## グラフの見方

- 価格推移グラフは「最安単価」と「相場（中央値）」の2本線です。
- 横軸の刻みは6時間（00時・06時・12時・18時）です。
- 価格の上下は、値付けそのものの変更よりも、安い出品の出現・終了によるものが大半です。

## 注意

- 表示価格はチェック時点のものです。購入前に必ず商品ページで在庫・送料・製造年を確認してください。
- データは最大で約1時間前のものになります。
